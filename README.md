# LCEDA-sch-net-fanout · 原理图引脚网络扇出

嘉立创EDA专业版（EDA Pro）扩展：选中 MCU、FPGA 等多引脚原理图器件，一键为**所有尚未连接网络的引脚**创建以**引脚名**命名的网络（引出导线 + 网络标签/网络端口），方便把大量引脚网络引出并连接到其他地方。

姊妹项目：[LCEDA-pcb-autofanout](https://github.com/liuem/LCEDA-pcb-autofanout)（PCB 电源地就近打孔）。

## 功能

1. **一键创建**：菜单「原理图编辑 - 引脚网络扇出 - 创建元件引脚名网络」。对选中器件的每个引脚：
   - 已有网络（网表可查）或已有导线连接的引脚自动跳过；
   - 其余引脚沿**引脚朝向**（按器件外接盒自动判定，四边引脚分别向左/右/上/下引出）创建一段**承载网络名的导线**——导线起点精确落在引脚端点，保证直接电气连接；
   - 网络名即引脚名。专业版的"网络标签"是**虚拟的**（放置标签=给导线设名称属性），所以导线带上网络名后画布会原生显示该名称，当前所有版本（含 V3.2.149）开箱即用；EDA v4+ 客户端可选 BETA 的 `createNetLabel` 精确定位标签位置。
2. **忽略名单**：常见电源/地（VCC/VDD/GND/±电源…）与 NC 默认忽略，设置页可增删，支持 `*` 通配；对完整引脚名与分段后的基名都匹配。
3. **前缀/后缀**：如 `MCU_` / `_N`，便于之后在网络管理器按名称搜索统一处理。
4. **放置方式**：
   - *直接放在元件引脚上*：沿朝向引出固定长度（默认 300mil，可设）；
   - *跟随鼠标*：执行命令时鼠标在哪，标签列就锚定在哪——水平引脚的标签全部引到鼠标所在竖列、垂直引脚引到鼠标所在横列，成列对齐（自动钳位到器件外侧）。
5. **长引脚名取段**：如 `USART1_TX/PB6`，分隔符（默认 `/`，可改）取第几段（支持负数从尾部数，越界自动钳位）。
6. 预览（不改画布）、一键清理本插件创建的导线/端口、诊断明细输出到控制台。

> 说明：原理图扩展 API 无鼠标移动事件，「跟随鼠标」以**命令触发时的鼠标位置**为锚点实现（标签列锚定鼠标位置），而非粘贴式实时拖拽跟随。

## 使用

1. 安装：EDA Pro → 高级 → 扩展管理器 → 导入扩展，选择 `build/dist/lceda-sch-net-fanout_vX.Y.Z.eext`；
2. 打开原理图，选中一个或多个器件；
3. 菜单「引脚网络扇出」→ 建议先「预览」确认 → 「创建元件引脚名网络」；
4. 「设置面板…」调整忽略名单、前后缀、取段规则、放置方式等（改动即保存，下次执行生效）。

## 开发

```bash
npm install
node test/run-offline.ts   # 离线测试（名称/网表/几何/规划/写回）
npx eslint src test
npm run build              # 产出 build/dist/lceda-sch-net-fanout_vX.Y.Z.eext
node test/verify-pkg.cjs   # 包内容核验
```

- 单位：原理图画布 1 单位 = 0.01 英寸 = 10mil；默认网格 10 单位（100mil）。
- 判断“已有网络”：优先解析 Protel2 网表（`sch_Netlist.getNetlist`），辅以已有导线端点几何贴合。
- 网络名形式：默认 `auto`——v4+ 有 `createNetLabel`（BETA，"ADD since EDA v4"，V3.2.149 尚未发布）就精确定位标签，否则用导线原生虚拟网络标签（全版本）；网络端口为可完全 API 清理的备选。
- 清理：默认形式（导线网络名）与网络端口均可完整 API 清理；若用 v4 网络标签（属性图元，API 暂不支持删除），删导线后如有残留标签可框选删除。
